## 3. Results and observations

MarkText  software was exceptionally good for me. I used VS code at first but the software showed some glitches and some functions were relatively inconvenient for me. Obsidian was unnecessarily too heavy and Typora was a paid software which pushed me to look for free alternatives. I found [MarkText](https://github.com/marktext/marktext) on a GitHub repository by [MIT](https://github.com/marktext/marktext/blob/develop/LICENSE)  which is a open source free software with over 60000 stars. The software was exceptionally lightweight. It has all the necessary functions and features the other text editors were providing without any extra distractions or heavy load. The key feature of the software was it works like Typora where the texts are converted into readable markdown format real time without using and side view for output. The app was also very convenient for not having any other distractions.
